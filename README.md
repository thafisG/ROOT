# 🌱 ROOT

> Build better habits, one workout at a time.

ROOT reúne hábitos saudáveis, treino de academia, registros de nutrição e recomendações personalizadas. A versão atual salva os dados no dispositivo.

O principal objetivo do projeto é desenvolver um **Recommendation Engine** capaz de aprender com as interações do usuário e sugerir atividades que incentivem uma rotina mais equilibrada.

> 🚧 Projeto em desenvolvimento.

## 🚀 Tecnologias (previstas)

- Angular
- TypeScript
- SCSS
- PWA
- LocalStorage

## 🧑‍💻 Execução local

Requer Node.js `22.22.3` e npm `11.13.0`. No PowerShell:

```powershell
cd frontend/root-web
npm install
npm start
```

Abra `http://localhost:4200`. Para gerar a versão de produção, use `npm run build` na pasta `frontend/root-web`.

O perfil e o histórico ficam salvos neste dispositivo; a entrada local pelo e-mail não sincroniza entre aparelhos.
